# NES Emulator
https://www.nesdev.org/wiki/Instruction_reference#ADC - This resource is particularly great for understanding what each of these instructions do and how they work with registers.

The end goal of this emulator is to get the original Legend of Zelda game from 1986 running on this emulator. By that point I will have learned a boatload about how emulator development works as well. It's been quite fascinating so far and I hope to keep up with this.
